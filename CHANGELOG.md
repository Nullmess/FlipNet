# Changelog

## [1.0.1]

- Added Android file manager for Flipper storage
- Added multi-file/folder upload, download, rename, delete and folder creation
- Merged Monitor and Phone into Companion
- Improved Files navigation and FNFS reliability
- Fixed legacy data migration and backup handling
- Improved Alpine Linux compatibility

## [1.0.0]

- First stable public release
- USB and BLE gateway transports
- Strict USB priority in Auto mode
- PC and Android companions
- Dynamic capability menus
- Network, Internet, system and automation tools
- Declarative plugin support
- Stable Android live console
- Official FlipNet branding
- Android Docker build without runtime SDK downloads
- Direct APK build with an explicit and validated Android package
- Java 8 lambda support in the direct Android build
